# Park It - Java Final Project

## Project Overview
A Java-based parking simulator following the MVC (Model-View-Controller) architecture and utilizing Maven for dependency management and testing.

## MVC Architecture
The project is organized into three primary layers:
- **Model**: Manages game state, car physics, player statistics, and timing logic.
- **View**: Handles rendering of the game world, UI screens, and overlays.
- **Controller**: Manages user input and navigation logic.

## Design Patterns
- **Singleton**: (Planned) Used to manage a single instance of the Game Model.
- **Observer**: (Planned) Used to update the View when the Model changes.

## Running the Project
This is a Maven project. Use the following commands:
- **Compile**: `mvn compile`
- **Run Tests**: `mvn test`
- **Build**: `mvn package`
